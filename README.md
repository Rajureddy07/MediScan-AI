# 💊 MediScan AI

AI-powered medicine recognition system that identifies medicines from:

- Full medicine strips
- Partial / cut strips
- Pill imprint codes

## Features

- OCR using EasyOCR
- Image preprocessing with OpenCV
- Medicine identification using RapidFuzz
- Medicine search
- Scan history
- Modern Streamlit UI

## Tech Stack

- Python
- Streamlit
- EasyOCR
- OpenCV
- Pandas
- RapidFuzz
